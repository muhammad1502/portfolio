# Security policy

This repository is the source of [mabddullah.vercel.app](https://mabddullah.vercel.app),
a static personal portfolio. It has no backend, accounts or user data.

## Reporting a vulnerability

Please email **muhammaddabddullah@outlook.com** with a description, steps to
reproduce and the affected URL or file. The same contact is published in
[`/.well-known/security.txt`](https://mabddullah.vercel.app/.well-known/security.txt)
(RFC 9116).

Please don't open a public issue for security reports. You'll get a reply
within a few days.

## Scope

- The live site and its HTTP headers (defined in `vercel.json`)
- The code and dependencies in this repository
